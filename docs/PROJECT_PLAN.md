# Color For A Cause — Project Plan

A project of [Not By Chance Outreach](https://notbychanceoutreach.com/).

**Participation first. Crypto second.** Anyone can print a page and send art back without an account, wallet, or email.

## Milestone 1 — Public happy path (this delivery)

- Browse 24 coloring pages (easy / standard / detailed)
- Print one page (browser print + PDF + PNG)
- Activity packs (easy, mixed, full, custom)
- Submit finished art from a phone in ~2 minutes
- Versioned consent (draft, flagged for legal review)
- Honest empty Art Wall
- Host an Art Day + group submit
- Grown-ups / privacy / accessibility / community standards
- Staff dashboard: review → approve → public
- Impact data model (verified counts only; zeros until real)

## Milestone 2 — Production Firebase

- Provision Firebase project, App Check, staff Auth
- Deploy rules, functions, hosting
- Legal review of consent v1
- Staff training on moderation

## Explicitly later (modeled, not built)

Automated minting, marketplace, artist certificates, sponsor matching.

## Non-goals

Fake testimonials, fake impact totals, fake participant art, investment claims, guaranteed NFT conversion, guaranteed funding.
